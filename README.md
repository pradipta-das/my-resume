# pradipta.online

Portfolio and lead-generation site for Pradipta Das, built with Next.js (App Router), Tailwind CSS v4 and GSAP. Content comes from a headless WordPress at logicncolor.com.

## Getting started

```bash
cp .env.example .env.local   # then fill in the values
npm install
npm run dev                  # http://localhost:3000
```

`npm run build` makes a production build, and `npm run lint` checks the code.

## Pages

| Route | What it is |
| --- | --- |
| `/` | Homepage |
| `/about` | About me |
| `/case-studies`, `/case-studies/[slug]` | Case studies from the `case-study` post type |
| `/blog`, `/blog/[slug]` | The Journal: WordPress posts |
| `/cost-estimator` | AI cost estimator (Claude), saved to WordPress |
| `/free-consultation` | Consultation booking, saved to WordPress |
| `/resources`, `/resources/[slug]` | Free downloads, listed in `src/app/lib/resources.ts` (files go in `public/downloads/`) |
| `/privacy-policy`, `/terms-and-conditions` | Legal pages |

API routes: `POST /api/estimate` and `POST /api/consultation`.

## Project layout

```
src/app/
  components/   Page sections and shared UI (header, footer, forms, cards, cookie banner)
  lib/          Data and integrations: WordPress, case studies, blog, estimate (Claude),
                consultation, analytics (consent-gated GA4 + Meta Pixel), legal details
  utils/        GSAP helpers: section animations, border drawing, magnetic links
  input.css     All styles (Tailwind v4 theme and components)
wordpress/      WordPress plugins the site relies on (install on logicncolor.com)
```

## WordPress

The site reads WordPress over its REST API, server-side only, sending `WORDPRESS_API_SECRET` with every request. The plugins in `wordpress/` must be installed and active:

| Plugin | Purpose | wp-config.php |
| --- | --- | --- |
| `pradipta-rest-lock` | Blocks the REST API for anyone without the key, and accepts Application Password logins in `X-WP-Authorization` on hosts that drop the `Authorization` header | `PRADIPTA_API_SECRET` |
| `pradipta-redirect` | Sends visitors of logicncolor.com to pradipta.online | |
| `pradipta-estimates` | Stores cost estimates and emails the visitor a copy | `PRADIPTA_ESTIMATE_SECRET` |
| `pradipta-consultations` | Stores consultation requests, emails you a notification and the visitor an acknowledgement | (uses `PRADIPTA_API_SECRET`) |
| `pradipta-case-studies` | The Case Studies post type and its fields | |

To install one, zip its folder and upload it under Plugins → Add New → Upload Plugin.

Emails to visitors are sent with `wp_mail`, so they go out through whatever mail setup WordPress has. For reliable delivery, use an SMTP plugin with a transactional email service authenticated for your domain, then optionally set the sender in `wp-config.php`:

```php
define( 'PRADIPTA_MAIL_FROM', 'hello@pradipta.online' );     // must be an address your SMTP setup may send from
define( 'PRADIPTA_MAIL_FROM_NAME', 'Pradipta Das' );         // default
define( 'PRADIPTA_MAIL_REPLY_TO', 'hello@pradipta.online' ); // default: the WordPress admin email
```

## SEO

- **Metadata:** every page builds its canonical URL and Open Graph block with `pageAlternates()` and `pageOpenGraph()` from `src/app/lib/seo.tsx` (Next.js merges these shallowly, so a page's own block would otherwise drop the site name, locale and RSS link). Profile links for the footer and structured data live in `siteConfig.profiles`.
- **Share images:** generated by the `opengraph-image.tsx` files next to each page, all drawn by `src/app/lib/og.tsx` in the brand fonts from `assets/fonts` (SIL Open Font License). Blog posts show the featured image alongside the title once a post has one. Case studies use their WordPress image.
- **Structured data:** WebSite, Person and ProfessionalService on the homepage; BlogPosting and BreadcrumbList on posts; BreadcrumbList on case studies and resources.
- **Journal:** categories filter at `/blog?category=<slug>` (WordPress category slugs); the RSS feed is at `/feed.xml`.
- **Icons:** `src/app/icon.svg`, `apple-icon.png` and `favicon.ico` are the "P." from the logo.

## Analytics and privacy

Google Analytics and the Meta Pixel load only after a visitor accepts cookies (`src/app/components/CookieConsent.tsx`, `src/app/lib/analytics.ts`). If you add a tracking service or change what's collected, update the privacy policy (`src/app/privacy-policy/page.tsx`) and bump `CONSENT_VERSION` in `lib/analytics.ts` so visitors are asked again.
